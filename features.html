Features

What LazyVerilog does.

🎯

Accurate parsing

SystemVerilog is parsed by accurate parser: slang.

🎨

Formatting

Highly customizable formatter.

🚨

Lint diagnostics

Parse diagnostics, optional semantic diagnostics, and configurable naming and style rules.

🧭

Navigation

Go to definition, find references, and rename across your project files.

💡

Hover, completion, signature help

Symbol details, context-aware completion, and signatures for functions and tasks.

💬

Inlay hints

Port directions shown on every instantiation.

⚙️

RTL automation

AutoInst, AutoWire, AutoArg, AutoFunc, and AutoFF as code actions.

🌳

RTL tree

Browse the module hierarchy, forward or reverse.

🔌

Connect

Wire an output of one instance to an input of another.

⌨️

CLI tools

lazyverilog-fmt, lazyverilog-lint, and lazyverilog-rtltree for scripts and CI.
